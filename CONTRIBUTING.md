# Участие в проекте

Спасибо за интерес. Проект небольшой, но требования к оформлению кода строгие —
часть «странного» поведения была вызвана неочевидными особенностями WPF.

## Требования

- **Windows 10 1809+ / 11, x64**
- **.NET 8 SDK** (совместим с .NET 10 SDK)
- **Интернет** — тайлы карты и API OpenSky Network

```powershell
dotnet --version   # должен быть 8.0 или новее
```

## Сборка и запуск

```powershell
# Сборка
dotnet build FlightRadarScreensaver/FlightRadarScreensaver.csproj -c Release

# Публикация готового набора файлов
dotnet publish FlightRadarScreensaver/FlightRadarScreensaver.csproj -c Release -o publish
Copy-Item publish/FlightRadarScreensaver.exe publish/FlightRadarScreensaver.scr

# Диалог настроек
.\publish\FlightRadarScreensaver.exe /c

# Заставка на произвольной точке
.\publish\FlightRadarScreensaver.exe /s /lat 55.7558 /lon 37.6176 /zoom 9
```

Режимы: `/s` — заставка, `/p <hwnd>` — предпросмотр, `/c` — настройки, `/a` — пароль.

## Структура

```
FlightRadarScreensaver/
├── Models/        данные и настройки
├── Services/      HTTP-клиент OpenSky, разбор аргументов, работа с настройками
├── Views/         окно заставки и диалог настроек
├── WebAssets/     map.html + Leaflet (копируются в выходную папку)
├── Assets/        app.ico
└── tools/         генератор иконки
```

## Ловушки, о которые уже спотыкались

Проверьте себя, прежде чем менять этот код:

1. **Цвета в XAML только 6-значные.** `#ccc` — это CSS, WPF такой формат не
   понимает и падает с `XamlParseException`. Нужно `#CCCCCC`.
2. **Цвета в XAML нельзя писать `None`.** Валидные значения: `Transparent`,
   `#RRGGBB`, `#AARRGGBB`.
3. **Иконка не задаётся через `Icon="..."` в XAML.** Относительный URI
   ищется от папки файла разметки (`views/assets/app.ico`) — ищемое
   `LoadAppIcon()` в `App.xaml.cs`.
4. **WebView2 — это HWND-элемент.** Он перехватывает мышь и клавиатуру, поэтому
   маршрутизируемые события WPF до окна не доходят. Отсюда `AddHandler(..., true)`
   и опрос позиции курсора через `GetCursorPos`.
5. **Формат сообщений между C# и страницей.** `PostWebMessageAsJson` передаёт
   в JS объект, а JS обязан слать объект, а не `JSON.stringify(...)`.
   Иначе C# получит строковый литерал и не найдёт поля.
6. **Слушатель `message` в странице регистрируется при загрузке**, а не внутри
   функции инициализации — иначе команда `init` не дойдёт и карта не построится.
7. **Тайлы `tile.openstreetmap.org` использовать нельзя** — политика
   использования запрещает встраивание, OSM отвечает 403. Тайлы CARTO
   требуют API-ключ и отдают заглушки. Используем Esri.
8. **Фильтрация бортов — по расстоянию до центра карты.** Сортировка по модулю
   координат выберет самолёты над Атлантикой.

## Диагностика

Приложение пишет подробный лог:

```
%TEMP%\FlightRadarScreensaver-crash.log
```

Он показывает режим запуска, загрузку карты, ответы API, ошибки страницы,
итоговое количество бортов и причину выхода. Это первый источник информации
при разборе проблем.

Для проверки отрисовки страница один раз шлёт метрики холста
(`canvas diag`): размер, число непрозрачных пикселей, сколько бортов в кадре.

## Пул-реквесты

- Один логический изменение — один PR.
- Сборка должна проходить без предупреждений.
